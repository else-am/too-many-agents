# Advanced native actions

`bot.look(yaw, pitch, force=false)` uses radians (pitch -π/2..π/2); `lookAt(point, force=false)` targets a world point. `dig(block, forceLook, digFace)` takes `forceLook` true/false/`'ignore'` and `digFace` `'auto'` (default), `'raycast'` or a face vector. `digTime(block)` is an estimate from observed tools/effects; native mining decides completion. `targetDigBlock` tracks this script's mining. `stopDigging()` requests cancellation; the mining promise rejects if interrupted.

Placement helpers retain their distinct effects: `_genericPlace(reference, face, options)` performs native placement without requiring a changed destination; `_placeBlockWithOptions(reference, face, options)` verifies a placed block; `_placeEntityWithOptions(reference, face, options)` handles entity placement. Face vectors are cardinal unit vectors. Options include `offhand`, `forceLook` (boolean or `'ignore'`), `half` (`'top'`/`'bottom'`), `delta` (local cursor hit point), and the helper's destination checks. Use these when ordinary placement's default hit point/hand is insufficient; native reach, collision, permissions and expected state checks still apply. `_genericPlace` returns the reference position, `_placeBlockWithOptions` resolves after verifying the destination state changed, and `_placeEntityWithOptions` returns the new Entity (boats/rafts, spawn eggs, armor stands, end crystals only). A held item is required.

`activateEntityAt(entity, position)` takes a world-space interaction point (converted to an entity-local offset internally). `swingArm(arm='right', showHand=true)` (placement options also accept `swingArm` and `showHand`) queues a native swing. `setSettings({mainHand:'left'|'right'})` changes the native body hand setting; `bot.settings.mainHand` is observed state.

`setControlState(name, boolean)`, `getControlState(name)`, `clearControlStates()` support forward/back/left/right/jump/sprint/sneak. Setters queue native controls; flush with `await bot.waitForTicks(1)`. No custom physics is simulated. `stopMoving()` clears these and the current script's native translation without cancelling unrelated actions. Do not start navigation with held manual controls.

`moveVehicle(left, forward)` queues input in [-1,1] for eligible boats, saddled mounts and minecarts. Native steering, momentum, ownership and equipment requirements apply. `elytraFly()` starts native gliding when eligible; `fireworkRocketDuration` reports observed remaining attached-rocket duration. Stopping movement inputs does not promise to erase native gliding/vehicle momentum.

Creative APIs require native creative permission. `creative.startFlying()` and `stopFlying()` queue flight-state changes. `await creative.flyTo(position)` moves straight toward the target, collision checked, at up to 0.5 blocks/tick. It does not route around obstacles. A flight that fails (e.g. `creative_flight_obstructed`, timeout) turns flight off, so the body falls; `flyTo` rejects like `moveTo` (`MovementFailed`, `MovementAlreadyRunning`) and refuses to start with held manual controls. `stopMoving()` interrupts its promise with MovementStopped while retaining hover; `stopFlying()` explicitly disables flight. Script end disables script-owned flight.

`await creative.setInventorySlot(slot, itemOrNull, waitTimeout=400)` writes native inventory slots 1..45; 0 is a result slot. Construct local items with `new Item(type, count)` and explicit component patch arrays. No write bypasses native checks. `await creative.clearInventory()` clears occupied slots and can fail partially (`completedSlots`). Serialization uses the world's native registry mappings in `bot.nativeRegistries`; numeric IDs are not portable between worlds.

`tabComplete(text, assumeCommand?, sendBlockInSight?, timeoutMs=5000)` resolves with native suggestion matches; only `text` is used.  `setCommandBlock(position, command, {mode: 0..2 (default 2), trackOutput, conditional, alwaysActive})` requires Creative + commands and native operator permission. Ordinary chat beginning with `/` also requires Creative + commands. These APIs do not grant permissions.
