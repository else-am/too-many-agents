minecraft_run executes an async JavaScript function body with initialized bot, Vec3, Item, ChatMessage and MessageBuilder globals. Read the minecraft-scripting skill for normal usage and its task references for advanced operations. No imports, filesystem, network or credentials. console.log is captured; return JSON. Default deadline 120s, maximum 300s; CPU, memory and output are bounded.

Query observed state → await native actions → inspect results. bot.moveTo(position) uses the body's native navigation in loaded/simulated chunks and bounds, with explicit failure on non-arrival. bot.stopMoving() stops only this script's movement and clears controls; interrupted movement rejects with MovementStopped. Creative flyTo is straight, collision-checked translation, not route finding. Dig/place do not approach automatically.

This is a deliberate Mineflayer subset for a singleplayer NPC. Native permissions, ownership and world-session leases remain authoritative. Completed mutations remain after failure/cancellation. Never replay unknown outcomes; inspect first. Transport loss aborts execution without reconnect/replay. Reports include results, logs, recent action observations and body-release status. minecraft_cancel ends the running script and releases its controls.
